# Village Calendar - Monetization & Feature Roadmap

This document tracks the evolution of Village Calendar into a premium, sustainable platform. These features are being developed in the `feature/monetization-roadmap` branch.

---

## 🚀 Phase 1: The "Super Village" (Subscription Tier)
*Focus: Scale and Organization for Power Users*

- [ ] **Multi-Village Management**: Allow Parents to create and manage multiple distinct villages (School, Soccer, Neighborhood).
- [ ] **Extended Member Capacity**: Increase member limits (e.g., 50+ members for premium villages).
- [ ] **Custom Branding**: Allow Village Owners to upload a custom logo and set primary theme colors for their village.

## 🛠 Phase 2: Coordination Power Tools (Convenience)
*Focus: Time-saving automation for busy parents*

- [ ] **External Calendar Sync**: Two-way sync with Google Calendar, iCal, and Outlook.
- [ ] **Recurring Requests**: "Set it and forget it" scheduling for weekly pick-ups or recurring events.
- [ ] **Smart Reminders**: Automated "nudge" notifications for Helpers (e.g., 2 hours before a commitment).

## 🛡 Phase 3: The "Safety & Trust" Pack (Peace of Mind)
*Focus: Strengthening the community safety net*

- [ ] **Integrated Background Checks**: Integrated verification for Helpers via partners like Checkr.
- [ ] **The Village Vault**: Secure storage for emergency contact info, medical notes, and house "How-To" guides.

## 📸 Phase 4: Community & Memory Features (Engagement)
*Focus: Building stronger neighborhood bonds*

- [ ] **Village Shared Gallery**: A high-res photo space for village events and shared childcare moments.
- [ ] **Village Alert (Emergency)**: A "Red Alert" system for urgent, last-minute needs (e.g., "Stuck in traffic, school pick-up needed in 10 mins").

## 🤝 Phase 5: Local Marketplace & Partnerships
*Focus: Hyper-local economy*

- [ ] **The Village Swap**: A trusted marketplace for high-quality outgrown baby gear and clothes within the village.
- [ ] **Local Perks**: Referral-based deals with local kids' businesses (playgrounds, coffee shops).

---

## 🔔 Phase 6: Intelligent Audible Notifications
*Focus: Real-time, hands-free awareness*

- [ ] **Parent Audible Alerts**: Specialized sounds when a commitment is accepted (e.g., a "ding" or chime) so parents know they are covered without checking the phone.
- [ ] **Helper Audible Alerts**: Distinctive notification sounds when a new help request is posted in their village.
- [ ] **Custom Notification Tones**: Allow users to select from a curated library of "calm" or "urgent" notification sounds.

---

## 📈 Integration & Monetization Tech Stack
- **Payments**: Stripe Connect / RevenueCat (for Mobile IAP).
- **Notifications**: Expo Notifications + Firebase Cloud Messaging.
- **Storage**: Convex + AWS S3 / Google Cloud Storage.
