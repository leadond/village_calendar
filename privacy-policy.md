# Privacy Policy for Village Calendar

## Data Collection
Village Calendar collects minimal data necessary for app functionality:
- Email address for account creation
- Name for profile identification
- Help requests and responses within your village

## Data Usage
- Data is used solely for coordinating childcare within your village community
- No data is shared with third parties
- Calendar access is used only to add events you create

## Data Storage
- All data is securely stored using Convex database
- Data is encrypted in transit and at rest

## Contact
For privacy concerns, contact: support@villagecalendar.com
